用来以后的代码管理
对于EXAM1的三个任务的解释：
1.cpp：这里我使用了嵌套循环，当时写的时候最开始并没有想到冒泡循环，我在这里的思路是不断选出最小的数排到前面，虽然缺点是循环次数更多更加麻烦，但好像在这种小程序里面区别应该不会太大。
2.cpp：这里我先是对字符串定义name的要求用了char，并创建好了结构体，由于题目要求是动态创建，所以应当使用Student* stu = new Student;实现了题目要求的动态创建。同时题目要求在函数内部实现输入，因此我使用了cin->的形式
3.cpp:题目要求 color 是 string，number 是 int，并且是私有成员，这里我按照题目要求，把两个成员都放在 private 下面。这样类外部就不能直接访问，比如在 main 里写 car1.color = "红色"; 会编译报错。外部只能通过公有的成员函数来间接操作这两个数据。
题目要求构造函数初始化车辆颜色、车牌号信息，这里我用了初始化列表：
color(c) 表示用参数 c 初始化成员 color
number(n) 表示用参数 n 初始化成员 number
题目要求有析构函数，这里我使用
~Car() {
    cout << "析构函数被调用：销毁车辆 " << number << endl;
}析构函数的写法是 ~ + 类名，没有参数，没有返回类型。对象销毁前会自动调用它。
关于EXAM2的解释：
为了运行这个文件，首先这个文件是一个压缩包，因此我将.zip文件先打开研究了一下里面的内容，经过我学习的知识，我发现真正的文件都被放在了src这一个文件夹中，所以为了不出现识别问题，我将src里面的所有文件提取到了其他地方待命。随后我创建了一个工作空间，将所有待命中的文件放入我的workplace中，再确认了路径为workspace/src/包的路径后，我source了ROS2，随后使用colcon进行了编译，接着我source了我工作环境的环境变量，接着run了程序。一开始看到出来后的结果我有些不可置信，难以相信这是一个无限循环程序，在我检查了.cpp中的代码后，按照我的观察，好像可能应该就是这样输出的，希望我没有弄错吧。。。
